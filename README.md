# 🔋 배터리 성능 예측 시스템 (Battery Performance Predictor)

AI 기반 배터리 성능 예측 및 수명 분석 시스템입니다. Random Forest 알고리즘과 물리학 기반 모델링을 통해 배터리의 용량, 효율성, 전압 특성을 예측합니다.

## ✨ 주요 기능

- **🎯 성능 예측**: 충방전 사이클, 온도, C-rate 등을 고려한 배터리 성능 예측
- **📊 수명 분석**: 시간에 따른 배터리 건강도 변화 시뮬레이션
- **🌡️ 환경 영향 분석**: 온도와 사용 조건이 배터리 성능에 미치는 영향 분석
- **📈 시각화**: 6가지 그래프를 통한 종합적인 성능 분석
- **⚡ 실시간 예측**: 다양한 조건에서의 즉시 성능 예측

## 🔬 기술적 특징

### 물리학 기반 모델링
- **아레니우스 방정식**: 온도에 따른 배터리 열화 모델링
- **지수 감소 모델**: Q(t) = Q₀ × exp(-kt) 형태의 용량 감소
- **캘린더 에이징**: 시간 경과에 따른 자연 열화 고려

### AI 예측 모델
- **Random Forest**: 높은 정확도와 해석 가능성
- **다중 타겟 예측**: 용량, 효율성, 전압을 동시 예측
- **특성 중요도 분석**: 각 요인의 영향력 정량화

## 📊 예측 결과 해석

### 출력 값 설명
- **predicted_capacity**: 초기 용량 대비 현재 용량 비율 (0.0-1.0)
- **predicted_efficiency**: 에너지 효율성 (0.7-0.98)
- **predicted_voltage**: 부하 조건에서의 실제 전압 (V)
- **health_score**: 종합 배터리 건강도 (0-100%)

### 건강도 기준
- **90-100%**: 우수 상태
- **80-90%**: 양호 상태  
- **70-80%**: 교체 권장
- **70% 이하**: 교체 필수

## 📈 시각화 구성

시스템은 6가지 분석 그래프를 제공합니다:

1. **사이클 vs 용량**: 충방전 반복에 따른 용량 감소 추이
2. **온도 vs 효율성**: 온도 변화가 배터리 효율에 미치는 영향
3. **C-rate vs 전압**: 방전율에 따른 전압 강하 특성
4. **특성 중요도**: 각 요인이 용량 예측에 미치는 영향력
5. **배터리 수명**: 시간에 따른 건강도 변화 시뮬레이션
6. **3D 성능 맵**: 온도-C-rate-효율성 관계 3차원 시각화

## 🔍 모델 검증

시스템은 다음 메트릭으로 성능을 평가합니다:

- **MAE (Mean Absolute Error)**: 평균 절대 오차
- **R² Score**: 결정계수 (모델 설명력)

일반적인 성능:
- 용량 예측: R² > 0.90
- 효율성 예측: R² > 0.85

## 📚 알고리즘 상세

### 용량 감소 모델
배터리 용량은 다음 요인들의 복합적 영향을 받습니다:

```
Capacity(t) = Cycle_factor × Temp_factor × Age_factor
```

- **Cycle_factor**: 1 - (cycles/5000) × (1 + C-rate × 0.2)
- **Temp_factor**: exp(-Ea/(kB×T)) 정규화
- **Age_factor**: exp(-months/120)

### 효율성 모델
```
Efficiency = Base_efficiency - Temp_penalty - C-rate_penalty
```

- **Base_efficiency**: 0.95 (95%)
- **Temp_penalty**: |T - 25°C| × 0.001
- **C-rate_penalty**: (C-rate - 1.0)² × 0.05
